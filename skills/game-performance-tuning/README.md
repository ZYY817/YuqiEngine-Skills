# game-performance-tuning

Windows 10/11 游戏与系统性能优化 skill：**先诊断瓶颈 → 分轮优化 → 复测回滚**，不玄学、不编数字。

## 文件

| 文件 | 作用 |
|---|---|
| `PROMPT.md` | 启动提示词模板（复制→填空→发给 AI） |
| `SKILL.md` | 主流程：问诊分诊、瓶颈分类、分轮优化、授权与验证规则 |
| `ITEMS.md` | 优化项库（顶部有按瓶颈的高杠杆速查表） |
| `SAFETY.md` | 红线清单与授权规则（无条件遵守） |
| `scripts/collect-diagnostics.ps1` | 只读诊断采集，顶部 `## SUMMARY` 是关键信号 |
| `scripts/collect-baseline.ps1` | 改前/改后系统指纹对比（清理/启动项类用） |

## 用法（配合 AI IDE：Cursor / Codex / Devin 等）

1. 把整个文件夹放进你的工作目录（IDE 对工作区外的文件访问可能受限），或记下绝对路径。
2. 打开 `PROMPT.md`，复制模板、填两个横线（skill 路径 + 你的问题）、发给 AI。例如：

   > 帮我优化一下电脑。
   > 先读 game-performance-tuning 里的 SKILL.md 了解规则，再结合我的目标给我优化方案。
   > 我的目标：玩《XX》掉帧

3. AI 会先跑只读诊断脚本（不改任何设置），再问 2~3 个问题，然后给你一份**编号清单**：
   - 🟢/🟡 标注每项风险与代价；
   - **你自己点的设置项** → 它教你点哪；
   - **改系统的命令项** → 它打包成一个脚本放 `tuning\` 文件夹，你**右键"以管理员身份运行"**才生效，跑之前自动导出备份；
   - 每轮改动记进 `tuning\log.md`，附带回滚命令；没效果就回滚。

## 注意

- 诊断报告含用户名、主机名、已装软件清单 —— AI IDE 会把上下文发到云端，别把报告整段贴到公开渠道。
- 仅支持 Windows 10/11；闪退/蓝屏/报错类问题会先进排障模式，修好再谈优化。
- 单项效果 <5% 视为存疑；这套流程不承诺"必涨 X 帧"，硬件到顶会直说。
