# 启动提示词模板

**两步上手**：
1. 把 `game-performance-tuning` 文件夹拖进 AI 工具的工作目录（或记下它的路径）；
2. 复制下面这段，填两个横线，发给 AI。

```text
帮我优化一下电脑。
先读 <skill文件夹路径> 里的 SKILL.md 了解规则，再结合我的目标给我优化方案。

我的目标：__________
```

**横线怎么填：**

- `<skill文件夹路径>`：文件夹在哪就写哪
  - 放进工作目录的 → 写 `game-performance-tuning`
  - 放别处的 → 写全路径，如 `C:\Users\57156\.config\mimocode\skills\game-performance-tuning\`
- `我的目标`：你的困扰，比如
  - 玩《黑神话》掉帧
  - 电脑开机慢、平时用着卡
  - 游戏闪退、报错、进不去
  - 越玩越卡 / 一顿一顿的 / 鼠标不跟手

不知道怎么说就写一个词，它会追问你。

（可选）想一次全改完就再加一句 `我想一次全改完`；不说就默认一步步来，每步都要你点头。

---

## 发送后会发生什么

1. 它先只读扫一遍你的电脑（不改任何东西），再问两三个问题。
2. 给你一份编号清单，每条写清楚：干嘛的、有啥好处、怎么改回去。
3. 你回编号就行（比如"做 1、3"）：
   - 要自己点的设置 → 它手把手教；
   - 要改系统的 → 它给你一个小脚本，**右键"以管理员身份运行"**才生效，改之前自动备份。
4. 改完按它的方法玩一会儿测一下，把数字报给它；没用就还原。
